# zebra-software.github.io

The website for **Zebra Software**: free and open-source software for Linux and Android, made since 2011.

Live at **https://zebra-software.github.io**

It's a plain static site, with no build step and no dependencies:

- `index.html` contains the page, its styles and a few lines of script
- `assets/` holds the logo, icons and background image

To preview it locally, open `index.html` in a browser.
